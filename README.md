# Carnet de religion

Un carnet pour apprendre la Sîra, le Fiqh, le Tawhid et les 40 hadiths d'an-Nawawî en jouant : leçons, quiz, niveaux, badges, devoirs et pensées.

- `index.html` : l'application (rien à modifier).
- `contenu.js` : les modules, leçons et hadiths. C'est ce fichier qui est mis à jour à chaque nouveau cours.

Les textes (versets, hadiths) sont vérifiés auprès de sources reconnues avant chaque mise à jour. La progression de chaque personne reste dans son navigateur.
